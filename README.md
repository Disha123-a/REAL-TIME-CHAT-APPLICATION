# Real-Time Chat Application using React and WebSockets

This project is a real-time chat application developed using **React.js** for the frontend and **WebSockets** with **Node.js** for the backend. The main objective of this application is to enable multiple users to communicate with each other instantly without refreshing the page. It demonstrates how real-time communication works in modern web applications using WebSocket technology.

The application allows users to enter a username and join the chat room. Once inside, users can send and receive messages in real time. Messages appear instantly for all connected users, creating a smooth and interactive chat experience similar to popular messaging platforms. Each user’s messages are displayed on one side of the chat window, while messages from other users appear on the opposite side. This improves readability and gives the interface a more realistic conversation feel.

The backend of the application is built using **Node.js** and the **ws (WebSocket)** library. The WebSocket server runs on a specific port and listens for incoming client connections. Whenever a user sends a message, the server receives it and broadcasts it to all connected clients. This ensures that every user sees the message at the same time. The server handles multiple connections simultaneously, making the application suitable for real-time communication scenarios.

The frontend is created using **React.js**, a popular JavaScript library for building user interfaces. React is used to manage the chat interface, message list, and user input. The application uses React hooks such as **useState** and **useEffect** to handle the WebSocket connection and update messages dynamically. This approach makes the code simple, modular, and easy to understand.

The user interface is designed to be clean, responsive, and easy to use. It includes a login screen for entering the username, a chat window to display messages, and an input area to type and send new messages. Messages are styled with different alignments and colors to distinguish between the current user and others, providing a familiar chat layout.

This project demonstrates important concepts such as:

* Real-time communication using WebSockets
* Frontend development with React.js
* Client-server architecture
* Event-based message handling
* Building responsive and interactive user interfaces

Overall, this real-time chat application is a beginner-friendly project that showcases how modern web technologies can be combined to create interactive applications. It serves as a strong foundation for more advanced features such as authentication, private messaging, message history storage, and deployment to cloud platforms.
